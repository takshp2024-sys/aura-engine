# Aura Engine

A luxury fashion styling application powered by Gemini AI and Firebase.

## Features
- **Personalized Styling**: Get AI-generated outfit recommendations based on your local weather and occasion.
- **Wardrobe Management**: Digitally organize your clothing items by category and color.
- **Firebase Backend**: Real-time cloud storage for user data.

## How to Run Locally
1. Clone this repository: `git clone https://github.com/takshp2024-sys/aura-engine.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Deployment
This project is automatically deployed via Vercel. 

## Built With
- **React**: Frontend framework.
- **Tailwind CSS**: Styling.
- **Firebase**: Database and Auth.
- **Google Gemini API**: AI Stylist engine.
